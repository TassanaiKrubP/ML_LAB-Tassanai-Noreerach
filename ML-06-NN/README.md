## การแบ่งข้อมูล

| ชุด | สัดส่วน | ใช้ทำอะไร |
|---|---|---|
| train | 70% | โมเดลเรียนรู้และปรับน้ำหนักจากชุดนี้ |
| validation | 15% | ตรวจสอบทุกจบ epoch เพื่อดูอาการ overfitting |
| test | 15% | สอบครั้งเดียวตอนจบ เป็นคะแนนที่รายงาน |

## สรุปผล

โครงสร้างที่มีชั้นซ่อนเพียงชั้นเดียว 128 นิวรอน ให้ผลดีที่สุดที่ val_accuracy 0.7519
และได้ accuracy บนชุด test เท่ากับ 0.7672 ทั้งที่มีพารามิเตอร์เพียง 1.57 ล้านตัว
น้อยกว่าโครงสร้าง 3 ชั้นที่มีถึง 6.46 ล้านตัว แสดงว่าการเพิ่มจำนวนชั้นและพารามิเตอร์
ไม่ได้ทำให้ผลดีขึ้นเสมอไป เมื่อปริมาณข้อมูลมีจำกัด

ในการทดลองรอบแรกที่ใช้ Dropout 0.3 พบว่า train accuracy ต่ำกว่า val accuracy
ซึ่งเป็นอาการ underfit เนื่องจาก Dropout ปิดนิวรอนทิ้งมากเกินไปสำหรับข้อมูลที่มีจำกัด
เมื่อลด Dropout เหลือ 0.1 และจำกัดจำนวนภาพให้ทุกคลาสเท่ากันที่ 582 ภาพ
accuracy เพิ่มขึ้นจาก 0.6977 เป็น 0.7672 และ f1-score ของคลาส Birds
ดีขึ้นจาก 0.51 เป็น 0.71

เมื่อพิจารณาผลรายคลาส Aeroplanes ทำได้ดีที่สุดที่ f1-score 0.90 ส่วน Birds และ Drones
อยู่ที่ 0.71 และ 0.70 ตามลำดับ

ข้อจำกัดของระบบคือ Neural Network แบบ Fully Connected ต้องคลี่ภาพให้เป็นแถวตัวเลข
12,288 ตัวก่อนเข้าโมเดล ทำให้ข้อมูลเชิงตำแหน่งของพิกเซลสูญหายไป
แนวทางการพัฒนาต่อคือการใช้ Convolutional Neural Network (CNN)
ซึ่งออกแบบมาสำหรับงานภาพโดยเฉพาะ
